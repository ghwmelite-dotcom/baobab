# Digest v2 — Featured + Companions with Images — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the text-only `DigestStrip` NTP component with a magazine-style "featured + companions" layout backed by image extraction (RSS embed + OG fallback), worker-proxied WebP resizing, R2 caching, and 2h refresh — preserving Bundle B's data-savings story via a slow-mode text-only fallback.

**Architecture:** Worker extends `assembleDigest` to extract image URLs during RSS parsing and fall back to `og:image` when RSS embeds are missing; pre-warms the lead-story hero into R2 during assembly and serves both variants via a new lazy `/api/digest/img/:sha` endpoint that resizes to WebP via Cloudflare Image Resizing on cache miss. Desktop renames `DigestStrip` → `DigestFeatured`, splits into `FeaturedHero` + `CompanionCard`, and branches on `useConnectionStore.isSlow` to skip image bytes with a session-scoped "Load images anyway" opt-in.

**Tech Stack:** Cloudflare Workers (Hono router, KV `PAGE_CACHE`, R2 `ASSETS`, Workers AI for summaries already wired, CF Image Resizing via `fetch` `cf.image` options), React 18 + Zustand on the desktop, Vitest everywhere. DOMPurify is already a dep but not used here.

```ts
export function extractRssImage(block: string): string | null {
  const mediaThumb = /<media:thumbnail[^>]*url=["']([^"']+)["'][^>]*\/?>/i.exec(block)
  if (mediaThumb) return mediaThumb[1] ?? null

  const mediaContent = /<media:content[^>]*url=["']([^"']+)["'][^>]*medium=["']image["'][^>]*\/?>/i.exec(block)
    ?? /<media:content[^>]*medium=["']image["'][^>]*url=["']([^"']+)["'][^>]*\/?>/i.exec(block)

  const enclosure = /<enclosure[^>]*url=["']([^"']+)["'][^>]*type=["']image\/[^"']+["'][^>]*\/?>/i.exec(block)
```

```ts
const OG_FETCH_TIMEOUT_MS = 3000
const OG_FETCH_USER_AGENT = 'Mozilla/5.0 (compatible; BaobabDigest/1.0; +https://baobab.africa)'

export async function extractOgImage(articleUrl: string, _env: Env): Promise<string | null> {
  try {
    const controller = new AbortController()
    const timer = setTimeout(() => controller.abort(), OG_FETCH_TIMEOUT_MS)
    try {
      const r = await fetch(articleUrl, {
        headers: {
          'User-Agent': OG_FETCH_USER_AGENT,
          'Range': 'bytes=0-30000',
          'Accept': 'text/html,application/xhtml+xml',
        },
        signal: controller.signal,
      })
      if (!r.ok && r.status !== 206) return null
      const html = await r.text()
      const m = /<meta\s+(?:property|name)=["']og:image["']\s+content=["']([^"']+)["']/i.exec(html)
        ?? /<meta\s+content=["']([^"']+)["']\s+(?:property|name)=["']og:image["']/i.exec(html)
      if (!m) return null
      const candidate = m[1] ?? ''
      if (candidate.startsWith('data:')) return null
      try {
        return new URL(candidate, articleUrl).toString()
      } catch {
        return null
      }
    } finally {
      clearTimeout(timer)
    }
  } catch {
    return null
  }
}
```

```ts
const IMAGE_FETCH_TIMEOUT_MS = 5000
const IMAGE_MAX_BYTES = 5 * 1024 * 1024
const SIDE_INDEX_TTL_S = 7 * 24 * 60 * 60
const VARIANT_WIDTHS: Record<'hero' | 'thumb', number> = { hero: 600, thumb: 200 }

async function sha256Hex(s: string): Promise<string> {
  const buf = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(s))
  return Array.from(new Uint8Array(buf)).map((b) => b.toString(16).padStart(2, '0')).join('')
}

export async function ensureImageInR2(
  env: Env,
  imageUrl: string,
  variants: ('hero' | 'thumb')[],
): Promise<string> {
  const sha = await sha256Hex(imageUrl)

  // Side-index write — always, regardless of variant fetch outcome.
  // (Other variants may be requested lazily later via the same sha.)
  await env.PAGE_CACHE.put(
    `digest-img-src:${sha}`,
    JSON.stringify({ url: imageUrl, addedAt: new Date().toISOString() }),
    { expirationTtl: SIDE_INDEX_TTL_S },
  )

  for (const v of variants) {
    const key = `digest-img/${sha}/${v}.webp`
    const exists = await env.ASSETS.head(key).catch(() => null)
    if (exists) continue

    try {
      const controller = new AbortController()
      const timer = setTimeout(() => controller.abort(), IMAGE_FETCH_TIMEOUT_MS)
      const r = await fetch(imageUrl, {
        signal: controller.signal,
        headers: { 'User-Agent': OG_FETCH_USER_AGENT },
        cf: { image: { width: VARIANT_WIDTHS[v], format: 'webp', quality: 75 } },
      } as RequestInit & { cf: { image: { width: number; format: string; quality: number } } })
      clearTimeout(timer)
      if (!r.ok) continue

      const contentLength = Number(r.headers.get('Content-Length') ?? '0')
      if (contentLength > IMAGE_MAX_BYTES) continue

      const body = await r.arrayBuffer()
      if (body.byteLength > IMAGE_MAX_BYTES) continue

      await env.ASSETS.put(key, body, { httpMetadata: { contentType: 'image/webp' } })
    } catch {
      // swallow; lazy path will retry
    }
  }

  return sha
}
```

```ts
function cacheKey(): string {
  const d = new Date()
  const yyyy = d.getUTCFullYear()
  const mm = String(d.getUTCMonth() + 1).padStart(2, '0')
  const dd = String(d.getUTCDate()).padStart(2, '0')
  // Bucket to 2-hour windows so the key stays stable across requests within each window.
  const hh = String(Math.floor(d.getUTCHours() / 2) * 2).padStart(2, '0')
  return `digest:${yyyy}-${mm}-${dd}-${hh}`
}

const CACHE_TTL_SECONDS = 2 * 60 * 60 // 2h
const ASSEMBLY_LOCK_TTL_S = 60

function lockKey(): string {
  return `digest-lock:${cacheKey().slice('digest:'.length)}`
```

```ts
export async function assembleDigest(env: Env): Promise<DigestItem[]> {
  const key = cacheKey()
  const lock = lockKey()

  // Cache hit
  const cached = await env.PAGE_CACHE.get(key)
  if (cached) return JSON.parse(cached) as DigestItem[]

  // Acquire lock; if held by another worker, poll the cache with backoff.
  const lockHeld = await env.PAGE_CACHE.get(lock)
  if (lockHeld) {
    for (const ms of [250, 500, 1000]) {
      await new Promise((r) => setTimeout(r, ms))
      const c = await env.PAGE_CACHE.get(key)
      if (c) return JSON.parse(c) as DigestItem[]
    }
    // Lock holder died — proceed and re-acquire.
  }
  await env.PAGE_CACHE.put(lock, '1', { expirationTtl: ASSEMBLY_LOCK_TTL_S })

  try {
    // Fetch all sources in parallel (existing logic).
    const settled = await Promise.allSettled(SOURCES.map((s) => fetchSource(s)))
    const raw: RawItem[] = []
    for (const result of settled) {
      if (result.status === 'fulfilled') raw.push(...result.value)
    }

    // Sort newest first, dedupe by URL, cap.
    raw.sort((a, b) => Date.parse(b.publishedAt) - Date.parse(a.publishedAt))
    const seen = new Set<string>()
    const deduped: RawItem[] = []
    for (const r of raw) {
      if (seen.has(r.link)) continue
      seen.add(r.link)
      deduped.push(r)
      if (deduped.length >= FINAL_ITEM_LIMIT) break
    }

    // Summarize in parallel. (`summarize` is the existing helper at line ~125 of digest.ts;
    // signature: `async function summarize(env: Env, raw: RawItem): Promise<string>`.)
    const summaries = await Promise.allSettled(deduped.map((r) => summarize(env, r)))

    // OG fallback for items missing rssImage — parallel, bounded by deduped.length.
    const ogImages = await Promise.allSettled(
      deduped.map((r) => r.rssImage ? Promise.resolve(r.rssImage) : extractOgImage(r.link, env)),
    )

    const items: DigestItem[] = []
    for (let i = 0; i < deduped.length; i++) {
      const r = deduped[i]!
      const summary = summaries[i] && summaries[i]!.status === 'fulfilled' ? (summaries[i] as PromiseFulfilledResult<string>).value : r.title
      const imageUrlRaw = ogImages[i] && ogImages[i]!.status === 'fulfilled' ? (ogImages[i] as PromiseFulfilledResult<string | null>).value : null

      let imageUrl: DigestItem['imageUrl'] = null
      if (imageUrlRaw) {
        // Pre-warm the hero only for items[0]; for everything else, just compute the sha
        // and write the side-index so the lazy endpoint can serve them later.
        const sha = i === 0
          ? await ensureImageInR2(env, imageUrlRaw, ['hero'])
          : await sha256Hex(imageUrlRaw)
        if (i !== 0) {
          await env.PAGE_CACHE.put(
            `digest-img-src:${sha}`,
            JSON.stringify({ url: imageUrlRaw, addedAt: new Date().toISOString() }),
            { expirationTtl: SIDE_INDEX_TTL_S },
          )
        }
        imageUrl = {
          hero: `/api/digest/img/${sha}?v=hero`,
          thumb: `/api/digest/img/${sha}?v=thumb`,
        }
      }

      items.push({
        id: itemId(r),  // existing helper at line ~145 of digest.ts; signature: `function itemId(raw: RawItem): string`
        title: r.title,
        summary,
        source: { id: r.source.id, name: r.source.name, country: r.source.country },
        url: r.link,
        publishedAt: r.publishedAt,
        imageUrl,
      })
    }

    await env.PAGE_CACHE.put(key, JSON.stringify(items), { expirationTtl: CACHE_TTL_SECONDS })
    return items
  } finally {
    // Release lock by best-effort delete; expired naturally in 60s anyway.
    await env.PAGE_CACHE.delete(lock).catch(() => {})
  }
}
```

```ts
// worker/src/services/digest-img.ts
import type { Env } from '../types'

const VARIANT_WIDTHS: Record<'hero' | 'thumb', number> = { hero: 600, thumb: 200 }
const IMAGE_FETCH_TIMEOUT_MS = 5000
const IMAGE_MAX_BYTES = 5 * 1024 * 1024
const CACHE_CONTROL = 'public, immutable, max-age=2592000'

export async function serveImage(
  env: Env,
  sha: string,
  variant: 'hero' | 'thumb',
): Promise<Response> {
  const r2Key = `digest-img/${sha}/${variant}.webp`

  // 1. R2 hit
  const obj = await env.ASSETS.get(r2Key)
  if (obj) {
    return new Response(await obj.arrayBuffer(), {
      headers: {
        'Content-Type': 'image/webp',
        'Cache-Control': CACHE_CONTROL,
      },
    })
  }

  // 2. R2 miss → side-index lookup
  const indexRaw = await env.PAGE_CACHE.get(`digest-img-src:${sha}`)
  if (!indexRaw) return new Response('not found', { status: 404 })

  let entry: { url: string }
  try {
    entry = JSON.parse(indexRaw) as { url: string }
  } catch {
    return new Response('not found', { status: 404 })
  }
  if (!entry.url) return new Response('not found', { status: 404 })

  // 3. Fetch + resize
  const controller = new AbortController()
  const timer = setTimeout(() => controller.abort(), IMAGE_FETCH_TIMEOUT_MS)
  try {
    const r = await fetch(entry.url, {
      signal: controller.signal,
      headers: { 'User-Agent': 'Mozilla/5.0 (compatible; BaobabDigest/1.0; +https://baobab.africa)' },
      cf: { image: { width: VARIANT_WIDTHS[variant], format: 'webp', quality: 75 } },
    } as RequestInit & { cf: { image: { width: number; format: string; quality: number } } })
    if (!r.ok) return new Response('upstream', { status: 502 })

    const contentLength = Number(r.headers.get('Content-Length') ?? '0')
    if (contentLength > IMAGE_MAX_BYTES) return new Response('too large', { status: 502 })

    const body = await r.arrayBuffer()
    if (body.byteLength > IMAGE_MAX_BYTES) return new Response('too large', { status: 502 })

    await env.ASSETS.put(r2Key, body, { httpMetadata: { contentType: 'image/webp' } })

    return new Response(body, {
      headers: {
        'Content-Type': 'image/webp',
        'Cache-Control': CACHE_CONTROL,
      },
    })
  } catch {
    return new Response('upstream', { status: 502 })
  } finally {
    clearTimeout(timer)
  }
}
```

```tsx
// apps/desktop/src/digest/CompanionCard.tsx
import { useState } from 'react'
import { useTabsStore } from '~/state/tabs.store'
import type { DigestItem } from './digest.store'

interface Props {
  item: DigestItem
  showImage: boolean
}

function timeAgo(iso: string): string {
  const ms = Date.now() - Date.parse(iso)
  if (Number.isNaN(ms) || ms < 0) return 'just now'
  const h = Math.floor(ms / 3_600_000)
  if (h < 1) return `${Math.floor(ms / 60_000)}m`
  if (h < 24) return `${h}h`
  return `${Math.floor(h / 24)}d`
}

export function CompanionCard({ item, showImage }: Props) {
  const [imgFailed, setImgFailed] = useState(false)
  const open = () => { void useTabsStore.getState().openTab(item.url) }
  const onKey = (e: React.KeyboardEvent<HTMLButtonElement>) => {
    if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); open() }
  }
  const renderImage = showImage && item.imageUrl && !imgFailed

  return (
    <button
      type="button"
      onClick={open}
      onKeyDown={onKey}
      aria-label={`${item.title} — Read on ${item.source.name}`}
      style={{
        display: 'flex',
        gap: renderImage ? 10 : 0,
        background: '#fffaf2',
        border: '1px solid rgba(196,136,31,0.25)',
        borderRadius: 10,
        padding: renderImage ? 8 : '10px 12px',
        textAlign: 'left',
        cursor: 'pointer',
        alignItems: 'center',
      }}
    >
      {renderImage && item.imageUrl && (
        <img
          src={item.imageUrl.thumb}
          alt=""
          loading="lazy"
          onError={() => setImgFailed(true)}
          style={{ flex: '0 0 56px', width: 56, height: 56, borderRadius: 6, objectFit: 'cover' }}
        />
      )}
      <div style={{ flex: 1, minWidth: 0 }}>
        <div style={{
          fontSize: 9, color: '#8a6e3a',
          letterSpacing: '0.1em', textTransform: 'uppercase',
        }}>{item.source.name} · {timeAgo(item.publishedAt)}</div>
        <div style={{
          fontFamily: "'Iowan Old Style', 'Palatino Linotype', Georgia, serif",
          fontSize: 12, color: '#3c1810', fontWeight: 500,
          lineHeight: 1.2, marginTop: 2,
          display: '-webkit-box', WebkitLineClamp: 2, WebkitBoxOrient: 'vertical',
          overflow: 'hidden',
        }}>{item.title}</div>
      </div>
    </button>
  )
}
```

## Notes for executors

- **Worker test runner:** repo uses Vitest at the worker root. Run from inside `worker/`: `npx vitest run <path>` or `npm test`. Do NOT run vitest from project root.
- **Desktop test runner:** Vitest with React Testing Library + jsdom. Run from inside `apps/desktop/`. `setupFiles` already wires `@testing-library/jest-dom`.
- **CF Image Resizing assumption:** the OHCS Workers account must have CF Image Resizing enabled. If `fetch(url, { cf: { image: {…} } })` returns the original bytes unchanged (silent fallback), check the Cloudflare dashboard → Speed → Optimization → Image Resizing. The plan's `serveImage` swallows resize failures (stores original bytes) so the user-facing path stays functional even if CF Image Resizing isn't available — but bandwidth gains evaporate. Surface this in the smoke check on Step 5 (a 600KB hero implies no resize is happening).
- **No new secrets needed.** Worker already has `ASSETS` R2 binding and `PAGE_CACHE` KV binding configured in `wrangler.toml`.
- **r39 client compat:** old desktops keep working. The worker grows `imageUrl` on the response; old `DigestStrip.tsx` simply ignores unknown fields when destructuring.
- **Backwards compat for old digest cache keys (`digest:YYYY-MM-DD`):** they expire naturally in 12h via their existing TTL. Once expired they're gone. No migration step required.
