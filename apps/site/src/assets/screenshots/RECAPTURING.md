# Screenshot capture procedure

Capture from the desktop app at 1280x800 window size, 2x DPI.
Save as PNG; filenames match the FeatureBlock id (reader.png, grove.png, search.png, translate.png, adblock.png, data.png).
Update each FeatureBlock's screenshotSrc prop to `/src/assets/screenshots/<id>.png`.
Real screenshots are captured manually in Task 14.
